  • Performance on very low-end Androids may need Low preset.

How to Play Wi-Fi / Hotspot Multiplayer

  1. Host: Open FrogRunner on one device → Main Menu → Multiplayer → Host Room.
  2. Players: On other devices (same Wi-Fi or hotspot), open the game → Multiplayer → Join Room.
  3. Devices must be on the same network (Wi-Fi router or phone hotspot).
  4. Enter a unique player name (duplicates are rejected).
  5. Host starts the run; everyone races to the finish. First to finish earns the most points.

Tip: If discovery fails, make sure no firewall blocks UDP port 47777 / TCP 47778 on the host device.

Host It Yourself

🏠 Local (same Wi-Fi)

Run a tiny server from the Website/ folder:

cd Website
python -m http.server 8080

Then open http://<your-pc-ip>:8080 on your phone (same Wi-Fi/hotspot).

🌐 Publish to frogrunner.com

Free static hosting options:

  • GitHub Pages: push Website/ to a repo → Settings → Pages → deploy from main branch.
  • Netlify: drag-and-drop the Website/ folder at app.netlify.com/drop.
  • Cloudflare Pages: connect repo or upload; set build output to Website/.

Point your custom domain frogrunner.com to the host via DNS (CNAME/A records).
